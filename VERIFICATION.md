# Проверка проекта

- Установлены зависимости; package-lock.json включён в архив.
- Синтаксис серверных и клиентских JavaScript-файлов проверен через node --check.
- 18 проверок прошли через реальные HTTP-запросы к Express и PostgreSQL-движок PGlite: схема, повторное создание схемы, CRUD, поиск, фильтр, валидация, неизвестные ID, некорректный JSON, выдача HTML.
- PGlite использовался только во внешнем проверочном окружении; приложение подключается к обычному PostgreSQL через пакет pg. PGlite не включён в зависимости приложения.
- Соединение с отдельным сервером PostgreSQL и поведение интерфейса в браузере в этой среде не проверены.
